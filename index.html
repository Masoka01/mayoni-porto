Dashboard untuk mengelola lamaran kerja dan mengirim email ke banyak HRD sekaligus, lengkap dengan template dan status.

Personal project · 2026 · Private

Next.js 14TypeScriptFirebase AdminNodemailer

Konteks

Melamar kerja satu per satu berarti menyalin template, melampirkan CV, dan mencatat status secara manual. JobMailer menyatukan seluruh alur itu dalam satu dashboard.

Telegram Scheduler

Penjadwal pesan Telegram dengan opsi sekali, harian, mingguan, dan per jam — dijalankan otomatis lewat Vercel Cron.

Personal project · 2026 · Public

Next.js 14TypeScriptFirestoreTelegram APIVercel Cron

Konteks

Pesan rutin ke grup atau channel sering terlewat. Aplikasi ini menyimpan jadwal dan mengirimkannya otomatis melalui bot Telegram.

Yang dibangun

  • Form target chat ID, isi pesan HTML, dan waktu kirim.
  • Opsi pengulangan sekali, harian, mingguan, dan per jam.
  • Daftar pesan dengan status pending, sent, dan failed.
  • Refresh otomatis dan endpoint cron yang diamankan secret.

Arsitektur

  • Next.js 14 App Router dengan route /api/schedule dan /api/cron.
  • Firestore menyimpan scheduled_messages beserta nextRunAt.
  • Vercel Cron memanggil endpoint setiap menit; bot mengirim lewat Telegram API.
  • CRON_SECRET memastikan endpoint hanya bisa dipanggil oleh cron.

Tantangan

Pesan berulang harus dihitung ulang tanpa mengirim dua kali, dan endpoint cron tidak boleh terbuka untuk publik. Solusinya menyimpan nextRunAt per pesan serta memverifikasi Bearer token di setiap pemanggilan cron.

ESP32 Nav

PWA navigasi yang mengirim instruksi rute ke display ESP32 lewat BLE — dari peta di HP sampai firmware C++ di perangkat.

Personal project · 2026 · Public

Next.js 16React 19MapLibreWeb BluetoothC++ / ESP32

Konteks

Layar HP tidak selalu ideal saat berkendara. ESP32 Nav memindahkan instruksi navigasi ke display kecil yang terhubung langsung dengan browser lewat BLE.

Yang dibangun

  • Pencarian tujuan, pemilihan kendaraan, dan preferensi hindari tol.
  • Peta MapLibre/Leaflet dengan rute dan favorit.
  • Pengiriman maneuver ke ESP32 lewat Web Bluetooth GATT.
  • Firmware C++ yang menampilkan arah, jarak, dan teks instruksi.
  • PWA dengan share target dan fallback geocoder Nominatim/Photon.

Arsitektur

  • Next.js 16 + React 19; peta memakai MapLibre dan Leaflet.
  • Protokol BLE V1|code|distance|text, dikirim dalam chunk 20 byte.
  • Parser firmware menahan byte sampai newline dan mengantrekan frame.
  • Firestore menyimpan favorit; API /api/expand meresolve shortlink Maps.

Tantangan

Satu frame BLE bisa terpecah menjadi beberapa write, dan shortlink Google Maps berperilaku berbeda antara PWA di HP dan desktop. Solusinya parser frame dengan antrean di firmware, resolve shortlink di server, serta fallback Photon ketika Nominatim tidak menemukan hasil.

Anestesi Lab

Sistem manajemen laboratorium anestesi: jadwal praktikum, absensi QR, inventaris alat, dan pengguna dalam satu aplikasi.

Client project · 2026 · Private

React 18TypeScriptPostgreSQLPrismaExpress

Konteks

Laboratorium anestesi mengelola jadwal, alat, absensi, dan pengumuman dengan alur manual. Aplikasi ini menyatukan semuanya dengan akses berbeda untuk admin, laboran, dan mahasiswa.

Yang dibangun

  • Pengajuan dan approval jadwal praktikum beserta slot.
  • Absensi QR: generate QR per jadwal dan scan dari perangkat mahasiswa.
  • Inventaris alat/BHP, peminjaman, dan pengembalian otomatis.
  • Manajemen pengguna, pengumuman, dan pengaturan lokasi absensi.

Arsitektur

  • SPA React 18 + TypeScript + Vite, state dengan Zustand, routing React Router.
  • REST API Express + Prisma + PostgreSQL; autentikasi JWT Bearer.
  • Upload foto lewat signed upload Cloudinary.
  • Nginx menyajikan SPA statis dan mem-proxy /api ke backend.

Tantangan

Menjaga konsistensi stok dan absensi lintas role, terutama saat pengembalian alat dan approval jadwal terjadi bersamaan. Solusinya memusatkan akses data di API, melindungi route per role, dan menyediakan helper auto-return.
